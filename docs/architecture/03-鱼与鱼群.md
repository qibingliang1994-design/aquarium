- 鱼群行为修正（v2.1.3，来自全项目审查，浏览器实测）：
  - 活动范围：软边界从写死的 x ±1.5 / z ±0.48 改为按缸内腔（`steering.SWIM`）减体长余量（`swimLimits(L)`），
    硬约束跟随；经典缸实测脂鲤 x p5–p95 由约 ±1.36 扩到 ±1.8、z 由 ±0.4 扩到 ±0.6。沙面硬约束按 `sandHeight`。
  - 体型分离：同种分离半径 `sepRadius`（小鱼保持 0.16，锦鲤约 0.36）且越近推力越大；异种 `crossRadius` 按两鱼体长之和。
  - 底栖：物种字段 `hug`（鼠鱼、麒麟），下界贴着沙面起伏；喂食时附带 3 片快沉的沉底片（偏绿），只有底栖鱼追，
    中层鱼也不追沉到自己水层下界以下的饲料。实测 5 轮喂食鼠鱼由 0 颗变为 29 颗。
  - 顶流：相对水的目标速度改为水流推送量 ×(1±0.35)，最低游速在水流里放宽；此前恒逆游 minS×2.2 > 水流，全群挤在上游。
    溪流实测 89~92% 的鱼头朝上游，群中心在 x≈0 附近前后进退，贴两端玻璃 0%。
  - 神仙鱼领地：改为椭圆 `[0,0.8,-0.12,0.65,0.3]`，整圈都在活动范围内、切向力加大；此前圆心在边界外，99% 时间卡在一点。

- 鱼群贴墙"龙卷风"修复：Boids 分离 / 聚合各向同性，鱼群游到左右玻璃前被弹簧刹住、后排顶上来，水平挤到约 0.25 m，分离的压力只能往上下泄，整群立成一根竖柱（ADA 缸金三角灯实测竖直 0.8 m、y/x 达 3.3）。两处改动都在 `steering.js`：`wallFlat(p, lim)` 给出离左右玻璃的远近（弹簧起点前 0.6 m 从 0 到 1），`boidsAccumulate` 按它把竖直分离压到 0.3 倍、竖直聚合放到 3 倍，鱼群在墙边被压扁而不是拉高。只在墙边生效：全缸压扁会让鱼群水平铺得超过 `schoolRad`，被岩石一隔就分成两群。`boundaryAcc` 收到速度时，朝墙游的鱼在弹簧前 0.35 m 顺着自身 z 向拐弯，整群沿玻璃画弧掉头，不在同一个 x 上叠成一摞。按自身 z 向而不是"贴边朝缸心"：后者让前后两半往相反方向拐，鱼群会裂开。实测同起点冲墙：竖直峰值 0.68–0.82 → 0.52–0.59 m，最窄水平 0.25 → 0.47–0.57 m，y/x 峰值 2.3–3.3 → 0.8–1.1。墙边竖直跨度不再超过缸中巡游时。

- 照片皮鱼的实例化游动 + 新增六种鱼：①`fish/photo-fish.js`（游动着色器移植自 aquarium-editor 的 fishlib.js，MIT）：照片皮 GLB 带 `_FIN`（部位 0 躯干 / 1 背鳍 / 2 臀鳍 / 3 尾鳍 / 4 胸鳍 / 5 腹鳍 / 6 眼 / 7 鳃盖、权重、收拢角）与 `_PIV`（转动中心）顶点属性和 `extras.swim`（体长、波长、摆尾频率、包络）。原来只当静态模型用（加载时把 +X 转成 +Z、`decorateFishMaterial` 摆尾尖），贴图的透明度也被丢掉，鳍是整块不透明的片。现在每物种一个 InstancedMesh：头→尾行波 + 转弯时全身弯成弧、胸鳍外摆划水（外缘慢半拍）、腹鳍开合、背臀鳍像折扇收放、尾叶滑行时收拢、眼睛扫视并看向镜头、鳃盖起伏；逐实例 `aSwim`/`aFin` 两个 vec4。贴图透明度几乎只有 0/1，用 alphaTest 镂空（不用半透明排序）；鳍片按逆光强度补一点自身色当透光。与本项目的焦散/逆光合成：`decorateFishMaterial` 新增 `inst` 选项（焦散世界坐标乘 `instanceMatrix`）。L≥0.2 的鱼投影，深度材质同样变形并镂空。②`fish/photo-gait.js`（纯逻辑、有单测）：不照搬原项目的计划表，而是由鱼真实的运动（体长/秒的速度、加速度、转向角速度、惊吓、咬食、贴底）连续混合出悬停 / 胸鳍慢游 / 尾鳍巡游 / 刹车 / 转向各档的尾摆幅度频率、身体弯曲与各鳍姿态；`pectSwim`（慢游靠胸鳍的程度）与 `burst`（冲刺-滑行，小型灯鱼 1）是物种字段，`thrust` 把滑行减速 / 连摆加速反馈回 School 的速度，位移和尾摆对得上。相位只留小数（GPU 单精度）。③`School` 第四条路径 `school.photo`：模型头朝 +X，lookAt 后再绕自身 Y 转 -90°；俯仰限 42°（上浮换气、下沉觅食也是斜着游）；缩放 = `L / swim.length`；`pickRay` 椭球长轴按路径取 x 或 z。④`entities/fish/habits.js`（纯逻辑、有单测）：`cling`（小精灵）定时游到左右侧玻璃吸住、头朝上背朝缸内、边啃边挪，受惊或自然水域（`SchoolOpts.glass=null`）松开——不去前后玻璃：照片皮模型侧向薄，正面只看得到一条腹线；`breathe`（斗鱼、丽丽）每半分钟到一分钟上水面吞气，水层上限临时放到水面，碰到水面时 `ctx.onGulp` 在水面泛一圈涟漪。⑤换模型：霓虹脂鲤 / 金鱼（琉金）/ 鼠鱼（熊猫鼠）从 Quaternius 卡通低模换成照片皮，旧文件删除；新增 `rummy` 红鼻剪刀、`ember` 火焰灯、`oto` 小精灵、`ram` 荷兰凤凰、`scalare` 神仙鱼（淡水，肉食标签：会吃小灯鱼）、`gourami` 丽丽。`scripts/fish-import.mjs` 从 aquarium-editor 解码收录。荷兰草缸换成神仙鱼 + 凤凰 + 丽丽（原来的海水卡通蝴蝶鱼和照片鱼放一起很违和），ADA 岩组 / 苔石山 / 悠然 / 灰色山脉分别配红鼻剪刀 / 霓虹 / 火焰灯 / 金三角灯，都带两三条小精灵。图鉴预览照片皮模型保留原贴图、镂空、头朝 +X 直接侧身。性能：34 条霓虹的更新约 0.1 ms/帧；三角形比卡通模型多约 23 万（一个物种仍是一次绘制）。

- 低模海鱼与照片皮鱼统一画风（`fish/glb-style.js`、新增 `fish/body-axis.js`）：淡水鱼换成照片皮以后，礁缸 / 经典缸里的 Quaternius 海鱼（神仙、小丑、狮子、青蛙、鹦鹉）在旁边显得像软陶玩具——纯色块、没有鳞、白色被泛光糊成一团、水膜比照片鱼亮得多。
  1. **覆瓦状鱼鳞**：在（体长, 体高）平面上隔行错开半格排鳞心，每点归属"覆盖它且最靠头"的那片（前鳞压后鳞），露出的鳞缘是一道道凸向尾部的弧；鳞缘压暗，鳞片中部微隆起，用屏幕空间导数做凹凸（three `perturbNormalArb` 同式），隆起高度按"每格多少视空间单位"换算，与鱼的大小无关；鳞片小于约 2 px 时淡出，远处的鱼不闪。坐标用蒙皮前的物体空间（以体高为单位），鳞片贴着鱼身弯，不会在游动时滑动。第一版用 3D Voronoi，近看是不规则的鹅卵石 / 蜥蜴皮，改成成行的弧才像鱼鳞。
  2. **体长轴**：Quaternius 各模型的局部朝向不统一，`bodyAxis` 在与"向上"垂直的平面里每 5° 扫一个方向，顶点投影跨度最大的就是体长方向，再按眼睛质心落在哪一侧定头向（单测覆盖）。
  3. **斑驳与收色**：身体再乘一层低频值噪声（0.92~1.06）；神仙 / 小丑 / 狮子的白从 #fff 收到约 #ece9e1；水膜 0.6→0.45、镜面 0.7→0.55、环境反射 1.1→0.95，与照片鱼同一量级。花斑连鳍䲗无鳞（`scale:0`），只有斑驳；狮子鱼鳞更细（22 片 / 体高，默认 16）。
  4. **鳍逆光透光**：低模鳍与照片鱼的鳍（`vFinP`）都改用水草那套 `injectTranslucency`（光色已含阴影，`FIN_TR` 0.8），替掉照片鱼原来"按轮廓强度补自发光"的做法——那个在夜里和背光处也亮。

- 照片生成照片皮海鱼（试点：公子小丑；`scripts/photo-fish/`）：aquarium-editor 的 44 个照片皮模型全是淡水鱼，海水鱼只有 Quaternius 卡通款，两种画风同框差太多。先把经典缸鱼群改成全淡水照片鱼（海水鱼只留在珊瑚礁缸；已存档的经典缸要「恢复预设」才换），再做一条"侧面照片 → 同格式 glb"的生成线：
  1. **`build.py`（系统 Python：Pillow + numpy）**：按颜色抠鱼形（闭运算、种子点连通域、填洞、外扩），身体掩码 PCA 摆正后裁出贴图（透明处颜色外扩防 mip 黑边；alpha 0/1 走 alphaTest）。身体与鳍：大半径开运算 + 尾柄最细处截断；小丑鱼这类宽圆鳍分不开时，配置里直接给贴图坐标下的身体轮廓（对着输出的 `debug.png` 描）。鳍缘黑边按颜色抠会被切掉，`finRimPx` 只沿鳍往外收暗像素并取照片原色补回。网格是贴图上的规则格：身体按每列体高做椭圆截面鼓起（`z = w·√(1−u²)`，尾柄收薄），两面各一层；鳍是 z=0 单层，与身体在中面无缝相接；`_FIN` 身体 0 / 鳍 1（鳍逆光透光），`_PIV` 为 0（鳍不折叠）。**坑**：`Image.fromarray` 的图与数组共享只读内存，`ImageDraw.floodfill` 不 copy 会静默无效；身体边缘格里全落在 z=0 的三角形两面各出一次，Blender 报 mesh invalid——按顶点组去重。
  2. **`blender_export.py`（无头 Blender 4.5，按 dsh-blender-plugin 的 headless 优先路线直接 `blender -b`）**：建网格、UV、`_FIN`/`_PIV` 属性、贴图材质，`swim` 自定义属性 → 节点 extras，用与原模型同一个 Khronos 导出器写 WebP 贴图 glb。
  3. **结果**：7k 顶点、1024×672 贴图、约 0.5 MB；加载即走照片鱼路径（`photoSource` 自动识别，图鉴预览同样）。礁缸里小丑鱼成了真实的橙白黑边，旁边的卡通蝴蝶鱼 / 狮子鱼反差更明显——同一流程可继续做其余海鱼。照片 CC BY-SA 3.0，署名与授权写在 `public/fish-models/species/README.md`。

- 礁缸海鱼重做：照片皮 + 横向胸鳍 / 腹鳍，换掉狮子鱼与鹦鹉鱼（`scripts/photo-fish/`）。第一版照片生成的海鱼只有一张侧面薄片：照片里贴着身体的胸鳍也是平的，从正面、斜上方看鱼两侧光秃秃，狮子鱼的长鳍条与鹦鹉鱼的水下偏色照片也不好看——这两种下架，换成同样适合"侧面照片 → 扁身模型"的高扁身礁鱼：黄高鳍刺尾鱼 `ytang`、蓝倒吊 `btang`、镰鱼 `idol`。
  1. **活动鳍片**（看 aquarium-editor 霓虹 / 红鼻 / 熊猫鼠的做法：胸鳍是单独的 `_FIN` 部位 4 薄片、腹鳍部位 5，`_PIV` = 鳍基）：配置 `flaps` 给贴图坐标下手描的鳍轮廓 + 鳍基线（对着 `debug.png`，上面画了 50 px 刻度）。鳍从照片原色剪下（`growPx` 外扩带上鳍缘描边），放进贴图下方的图集条；每个点按到鳍基线的垂距绕鳍基转出 `splay` 角（沿鳍基分量不变、垂直分量 cos 留在侧面 / sin 离开体侧），鳍基嵌在椭圆体表上，左右镜像各一片；权重 = 垂距 / 最大垂距（鳍基 0 → 鳍梢 1），游动着色器原有的胸鳍划水、腹鳍开合直接生效（`pect_rest` -0.2）。原位置只挖掉伸出体外的部分，身体上画着的那片保留——aquarium-editor 的贴图也这样；试过按周围体色补平（`inpaint:true` 仍可选），小丑鱼白环被抹成一团、麒麟鱼糊一大块，比"鳍影"难看。**坑**：腹鳍基在腹缘时 z≈0，着色器靠 `sign(piv.z)` 分左右——鳍基中点至少偏出 1 px。`_PIV` 与顶点一样换成 Blender 坐标写入（导出器不转换自定义属性）。
  2. **抠图**：`colors` 改为可组合的规则列表（`warm` / `white` / `notBlue` / `bright`（可先模糊，`minRaw` 拦黑晕）/ `notWhite` / `blue` / `sat` / `dark` / `red`——纯蓝水红通道≈4，鱼哪怕是蓝的也带红），`drop` 剔除浅色杂点，`shrinkPx` 开运算后重取连通域，`rotate` 手动摆正（镰鱼照片头朝下斜 50°），`headRight` 先翻转；背景是浅沙、白色鱼身同样偏青的镰鱼直接手描 `roi`。**坑**：Pillow `MaxFilter(1)` 在 Windows 上原生崩溃（除零、退出码 127），`edgePx ≤ 1` 跳过。
  3. **下架迁移**：`scene-doc.js` `RETIRED_FISH = { lion:"idol", parrot:"btang" }`，`sanitizeFish` 把旧存档里的数量换给接替者（接替者已有数量时不动，单测覆盖），已存的礁缸不会突然少两种鱼；黄高鳍刺尾鱼要「恢复预设」才出现。礁缸不再有肉食鱼，混养提示随之消失。照片均为 Wikimedia Commons（CC BY / CC BY-SA），署名在 `public/fish-models/species/README.md`；狮子鱼 / 鹦鹉鱼的 Quaternius 与照片皮 glb、配色表一并删除。
