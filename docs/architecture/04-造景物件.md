- 沉木 / 树枝写实化（`wood`、`branchWood`、`logWood`）：原来是圆截面的均匀锥管（`natural-geo.js` `barkTube`，已删）+ 每段 4 点的折线 + 三平面木纹，近看是塑料管：截面正圆、木纹不顺枝走、末端像指尖、分叉处是插进去的。新增 `scenes/items/wood-geo.js`（纯几何，`tests/wood-geo.test.js`）：①`woodTube` 截面 = 扁圆（朝向沿枝缓慢旋转）+ 三瓣起伏 + 随木纹扭转的顺纹沟（沟数随径向段数取，不欠采样）+ 倒木的长裂缝 + 带凹心的树瘤 + 沿枝的鼓胀收腰；末端 `tip` 圆钝小尖 / `break` 参差劈裂断口（纤维长短不齐、断口浅色、朽心凹进），倒木两头和扎沙的起点都是断口；顶点色给沟/裂缝/瘤压暗、朝上的棱面泡浅、贴沙一段湿暗，每根枝风化程度不同。②UV：u 绕枝一周取整数圈（无接缝）、v 按弧长，`surface-tex.js` 新增 `injectUvTex` 按 UV 采样照片（屏幕导数重建切线系），木纹顺着枝条走；`aBark` 顶点属性按 3D 噪声给倒木成片树皮（高出木质一层），着色器里换成 `b_log` 树皮照片。③`branchCurve` 按"缓变的弯矩"转向（上一步的转向衰减着带到下一步）→ S 形弯，转向量按每步长度折算（细枝步子密，不折算会弯成钩）；高处平伸下垂、侧枝不钻沙。④`growLimb` 逐级分叉：子枝从母枝轴心长出，埋着的一段收细（敞口不露出母枝表面）、穿出处鼓起颈圈，母枝在分叉处鼓起；部分侧枝折断成短桩（`brk`/`stub`），杜鹃根的末梢挂一两根发丝细枝（`twigs`）。所有枝合成一个网格，三种沉木共用一个材质 `woodMat`（`logMat` 已删）、属性集一致 → 同一批次一次绘制（ashy 12 件沉木 = 1 个 BatchedMesh）。红沉木色调从橙红改成栗红褐。每件约 3~4k 三角（倒木约 2k），生成 2~10 ms。沉木拱的侧枝也走 `growLimb`（拱顶本身就高，不限高；原来套用 0.72 的限高，侧枝一出拱顶就被压弯成钩）。随后"灰色山脉"反馈木头太粗、不像造景沉木：`logWood` 原是基部半径 0.08 的原木（缩放 1.7 ≈ 直径 7 cm，九根堆起来像柴堆），改成灰沉木枝——基部半径 0.045、两级分杈、四成侧杈折断成短桩、主枝末端断口、灰褐水泡色、树皮只剩零星小片，侧枝朝上偏得少（`up` 0.35，不再一根根朝天戳）；`growLimb` 加管道模型收细：每分一次杈，母枝往后按截面积守恒（`√(1-0.6(rc/rp)²)`）细一截，末梢不再是一根长锥。预设位置与种子不动。
