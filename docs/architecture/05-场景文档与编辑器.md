- 摆放与投喂的缸内边界（v2.3.1，修复"鱼粮沉到缸外、水草穿玻璃"）：
  - 水体合成 pass 落地后跟进的设置项：画面里新增「水色浓淡」（`absorb`，默认 0.4）与「光柱」（`shafts`，默认 0.1）
    两个滑杆（1% 步进，`water-pass` 的 uSigmaK / setShafts）；旧的网格光柱 `LightRays` 删除，`effects` 只剩气泡/雪/涟漪。
  - 饲料硬边界：`systems/feeder.js` 每帧把饲料与碎屑夹在 ±2.2 / ±0.8（= 鱼群巡游矩形，也在玻璃内壁之内），
    顺流漂到玻璃就停——不再用"漂出 |x|>2.2 就淡出"兜底（那条路会看着饲料掉到缸外才消失）。
  - 物件包络钳制：`scene-runtime.js` build 时量出物件局部满幅（含 InstancedMesh 全部实例），`place()` 按旋转/缩放换算
    世界包络，把中心点钳在玻璃内壁 `GLASS_INNER`（±2.265 / ±0.865，item-meta 导出）之内，水草另加摆动余量；
    钳制结果写回运行时副本，接地暗斑跟随。`limitsOf(id)` 对编辑器暴露同一套范围。
  - 数据侧估算 `placeLimits(type, s)`（item-meta）：玻璃内壁 − 占地半径×缩放 − 2 cm，夹在 `PLACE_BOUNDS` 内、
    触底 0.15；`sanitizeItem` 用它把旧存档贴边的物件拉回缸内。估算比精确包络松的部分由 place() 兜底。
  - 编辑器同一套边界：拖动/方向键微移/复制用 `limitsOf`（真实包络），新放/缩放用 `placeLimits` 估算；
    拖动与缩放/旋转滑杆在 moveItem 后按新包络回钳文档，选中圈与视觉一致。
  - 水草 radius 改为含叶片满幅的占地（长叶草 0.24→0.42、皇冠草 0.16→0.4 等），石拱桥/瓷罐同步调大：
    选中圈更贴实、默认摆放间距更合理。

- 致敬水景还原度第四轮（背景板 / 机位 / 水草形态，按原作同比例取样）：①背光幕两种布局（`tank.js`）：缺省 / 水墨主题仍放在后玻璃后 1.6 处，板面放大到 12.9×6.9、不透明核心覆盖所有预设机位看到的后玻璃（原来核心比缸窄，缸内上半与两角露出暗边）；`art:'screen'` 改为紧贴后玻璃的发光屏，宽 8.4（作品照机位透过侧玻璃的视线也落在屏上）、材质色 1.55 当光源用，主题可选光型 `screen:'sky'`（上亮下深的钴蓝，《苔石山》用）。②ADA 缸首个机位是"作品照"：`cams` 支持 `fit:[半宽, 半高, 前玻璃 z]`（main 按窗口宽高比推相机距离，缸宽正好撑满）与 `fov`（随运镜补间，切走时缓回 45°）；作品照用 26° 长焦，透视压平、侧玻璃从半幅的近四成缩到两成。缸型还可带 `dof`（景深倍率，ADA 0.35：作品照全景深，后景草不再被散焦冲淡发白）与 `grade`（调色尾段的饱和 / 反差，ADA 1.24 / 1.1），灯 `spotK` 1.15→1.5。③新水草：`bushMass` 圆顶灌丛——修剪过的有茎草在剪口分出侧芽，叶子几乎全挤在圆顶表面：几十根光秃的茎长到包络下方，各分 3~4 个短梢沿外法线散开、节间很密（`rotala` 圆叶节节菜橙红圆顶、`pearl` 珍珠草浅绿圆顶；第一版叶沿整根茎均匀分布，看上去是一把扫帚）；`starStem` 星状刺蕊草（每节一轮水平针叶）。圆顶与草毯 `noCast` 不进阴影 pass。④摆放钳制：数据侧 `placeLimits` 支持长条物件的椭圆占地（`ITEM_META.depth`，按转角投影）——原来倒木按圆形半径 0.6×1.8 钳，进深方向全部压到 z=±0.15、九根木头挤在同一条线上；运行时 `limitsOf` 水草只按包络 55%、石头 85% 让开玻璃（斜伸的外圈叶把包络撑大，后景草被整丛挤到缸中间）。⑤三幅预设按原作重排：《苔石山》山脊按原图逐段取样（缸宽比例 → 水体高度比例），29 块石柱用固定种子在页面里实测各自局部高度后反推缩放，峰顶正好落在山脊线上；苔石改柱状（高宽比约 2）加竖向裂隙，苔藓更亮更黄绿。《悠然》右侧三分之二用珍珠草圆顶 + 星状刺蕊草 + 绿宫廷堆到水体八成半，中间橙红圆顶。《灰色山脉》倒木挑种子：三根陡的爬到限高被压平成左上横臂，木堆左移 0.6；左侧长叶草长到水面，右侧低矮深灰石脊 + 珍珠草小丘；鱼换金三角灯。⑥水草按画质档减株：`plantKeep(level)` 1→0.54，`applyShore` 一并处理（每丛至少一株）。三幅满配（含阴影 pass）约 60~105 万三角形。

- 造景物件不再穿出玻璃 + 相机可以压低：①实测 9 个玻璃缸场景，灰色山脉的灰沉木枝从后玻璃探出最多 0.49、苔石化妆砂与几处水草也越界。原因是 `limitsOf` 按局部包围盒 × 转角绝对值估外沿（偏大），又给石头乘 0.85、水草乘 0.55 往回找补（偏小）。新增 `scenes/item-reach.js`（纯几何，`tests/item-reach.test.js`）：build 时 `footprintOf` 把所有顶点（含 InstancedMesh 每个实例）投到 xz、取 48 个方向的支撑点；`reachOf` 按当前转角缩放算出四个方向的外沿，`rangeIn` 得出中心点的**分侧区间** `{x0,x1,z0,z1}`（物件往一侧伸得多只在那一侧让开；比缸还宽就放正中），硬物一个顶点都不出玻璃。运行时与编辑器（拖拽 / 微移 / 复制 / 实时预览）统一走 `clampTo`。②水草仍按包围盒 55% 让开（全量会把后景草挤到缸中间），越界的叶尖交给裁剪面：所有物件材质挂同一组四个 `THREE.Plane`（玻璃内壁往里 2 mm，`renderer.localClippingEnabled`），切掉的叶尖看上去就是顶在玻璃上；自然水域把面推到远处。③沉木生长加 `zMax`（`branchCurve` 在局部 |z| 到六成时收住外伸、到上限折回），红沉木枝 0.34、灰沉木枝 0.3，长条占地不会因侧枝横伸放不进缸深而被整体推到前景。④相机：原来 `maxPolarAngle` 固定 0.49π，最低只能平视目标点。玻璃缸改为每帧 `limitPolar()` 按当前距离反推——缸外不低于柜面上 0.14、缸内不低于沙面上 0.12，上限 0.62π；可以蹲到沙线高度仰看水景与水面下的全反射，拉远时自动收窄、不会钻到柜子和地面以下。自然水域仍以水平为限（低了会钻进地形）。
