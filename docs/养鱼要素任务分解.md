## 二、阶段 A · 常识纠偏

#### A1 物种生态标签 ⭐⭐ ✅
- **做法**：新增纯数据模块 `src/entities/fish/ecology.js`，按物种 id 给出 `water`（淡水/海水）、`temp`（冷水/温水/热带）、
  `predator`（是否会吞小鱼）。现状取值：

  | 物种 | 水 | 温 | 备注 |
  |---|---|---|---|
  | 霓虹脂鲤 tetra | 淡水 | 热带 | |
  | 金鱼 gold、锦鲤 koi | 淡水 | 冷水 | |
  | 鼠鱼 cory（花鼠 *C. paleatus*） | 淡水 | 温水 | 18–24 °C，和冷水、热带都合得来 |
  | 蝴蝶鱼 angel、小丑鱼、麒麟鱼、鹦鹉鱼 | 海水 | 热带 | `angel` 见 A3 |
  | 狮子鱼 lion | 海水 | 热带 | `predator` |

  图鉴卡在"水层 / 体长"旁加两个胶囊（`淡水 · 热带`）。不放进 `encyclopedia.js`，因为那里依赖 DOM / GLTFLoader，Node 单测加载不了。
- **改动**：`entities/fish/ecology.js`（新）、`ui/encyclopedia.js`、`ui/styles/encyclopedia.css`、`tests/ecology.test.js`（新）。
- **验收**：图鉴 9 种鱼都显示两项标签；单测断言 `FISH_IDS` 每个都有合法标签（新物种漏填即失败）。
- 风险：低。

#### A2 混养小知识（非阻断） ⭐⭐ ✅
- **做法**：`ecology.js` 增纯函数 `mixNote(fish)`，按优先级只返回一句（无则 `null`）：
  1. 淡水 + 海水 → "现实里淡水鱼和海水鱼没法同缸——在这里它们相安无事。"
  2. 冷水 + 热带（温水不触发）→ "金鱼锦鲤爱凉水，热带鱼要 26 °C 左右的温水；这缸的水刚好两边都喜欢。"
  3. 肉食鱼 + 体长 ≤ 其 0.7 倍的鱼 → "现实中狮子鱼会把小鱼当点心，这里它只是在巡游。"

  显示在造景"鱼群"页底部和图鉴页脚（当前水景）。不阻止、不打分、不改预设、不弹窗。
- **改动**：`entities/fish/ecology.js`、`editor/editor-panel.js`、`ui/encyclopedia.js`、`tests/ecology.test.js`。
- **验收**：单测覆盖 8 个预设的预期输出——经典混养/荷兰草缸 → 1，山间溪流/林间小河 → 2，珊瑚礁 → 3（麒麟鱼），
  锦鲤石庭/睡莲池塘/江南园林 → 无；编辑器里加减鱼时提示实时变化。
- 风险：低。文案要轻，是"冷知识"，不是"你做错了"。

#### A3 `angel` 物种位拆分 ⭐⭐（决策 #1：做）
- **问题**：`angel` 用的是 Quaternius 蝴蝶鱼模型，图鉴写海水蝴蝶鱼（*Chaetodon auriga*），开发记录里又叫"神仙鱼"；
  它同时出现在珊瑚礁（海水）和荷兰草缸（淡水）预设里。
- **推荐方案**：拆成两个物种——`angel` 改回淡水**神仙鱼**（*Pterophyllum scalare*：同一 GLB 换银底黑竖纹调色板），
  新增 `butterfly` 承接现在的海水蝴蝶鱼。存档迁移：主题为 `reef` 的水景把 `angel` 计数改到 `butterfly`，
  其余保持（=神仙鱼）。先在图鉴预览里看换色后像不像神仙鱼；不像就退回"只把荷兰草缸预设里的 angel 换掉"。
- **改动**：按 CLAUDE.md"新增物种"清单（`species.js` / `species-models.js FILES` / `SPECIES_META` / `PALETTES` /
  `FISH_IDS` `FISH_MAX` / `--sp` 三处 CSS）+ `scene-store` 版本号 +1 与迁移 + 单测。
- **验收**：荷兰草缸不再触发 A2 第 1 条；老存档的珊瑚礁打开后仍是蝴蝶鱼、数量不变、成长不丢。
- 风险：中（存档迁移；care 里 `fed.angel` 的成长要跟着迁）。

## 三、阶段 B · 设备与氛围

#### B1 贴壁设备物件 ⭐⭐
- **做法**：`设备` 组新增 3 件，全部纯装饰：
  - **加热棒**：斜贴后玻璃的玻璃管 + 吸盘，夜里有一颗暗红指示灯。
  - **温度计**：贴前玻璃内侧的液柱式；读数按在缸物种（全冷水 20 °C，含热带 26 °C，只有温水 23 °C），依赖 A1。
  - **过滤进出水管**：后壁的 U 形出水管 + 带滤网的进水管；出水口周期性在水面打涟漪（`ripples.spawn`）。

  新增摆放约束 `ITEM_META.mount:'wall'`：`sanitizeItem` 把 z 钳到后壁（温度计为前壁），编辑器拖拽只改 x；
  自然水域（没有玻璃）在编辑器面板里隐藏这类物件，运行时也跳过。
- **改动**：`scenes/item-meta.js`、`scenes/scene-doc.js`、`scenes/items/gear.js`（新）、`scenes/catalog.js`、
  `editor/scene-editor.js`（拖拽约束）、`editor/editor-panel.js`（按水域过滤）、`scene-store` 版本号 +1、`tests/scenes.test.js`。
- **验收**：三件设备可放、可拖（只沿玻璃横移）、可撤销；切到溪流时面板里看不到它们；
  老版本代码读到新存档时只读（沿用 v2.1.11 的版本闸门）。
- 风险：中（编辑器拖拽约束 + 存档版本）。**与 E1 合并成一次版本升级**。

#### B2 多气石 + CO2 细化器 ⭐
- **做法**：`Bubbles` 的单个发射点改为发射点数组（最多 4 个，总粒子池不变、按个数均分）；`scene-runtime` 收集全部气石。
  新增物件 **CO2 细化器**（贴后壁的小玻璃盘，可选依赖 B1 的 `mount`；B1 未做时先落在沙面）：
  细密小气泡，上升到半途缩小消失（"溶解"），不触发气泡声。
- **改动**：`systems/effects.js`、`scenes/scene-runtime.js`（`air` → `airs`）、`main.js`、`scenes/item-meta.js`、`scenes/items/gear.js`。
- **验收**：放 3 个气石三处都冒泡；CO2 气泡肉眼可见地在中层消失；气泡开关仍然整体生效。
- 风险：低。

#### B3 环境声景 ⭐⭐⭐
- **做法**：新增 `systems/soundscape.js`（`sound.js` 只保留短音效并暴露 `ctx/master`），全部 WebAudio 合成，按水域选声床，切场景交叉淡入：
  - **玻璃缸**：过滤出水细流声（高通噪声 + 随机颗粒），有气石时叠一层很轻的气泵低频。
  - **山间溪流**：潺潺水声（多路带通噪声随机调制）。
  - **林间小河**：慢流水声，偶尔一声鱼跃水花。
  - **池塘 / 园林**：白天稀疏鸟鸣（FM 啁啾），夜里虫鸣蛙声，随 `nightK` 交叉淡化。

  沿用设置里的"音效"开关。
- **改动**：`systems/soundscape.js`（新）、`systems/sound.js`、`main.js`（切场景时 `setKind`，每帧 `update(dt, nightK)`）。
- **验收**：8 个预设各自能听出区别；夜里池塘有虫鸣、白天没有；关音效全静音；切场景无爆音。
- 风险：低（纯合成），但听感需要反复调，留出调参时间。

#### B4 灯光定时器：跟随本地时间 ⭐⭐⭐ ✅
- **做法**：设置里新增开关「跟随本地时间」（与现有 180 s「自动昼夜」互斥）。纯函数 `clockNight(date, { on:'8:00', off:'21:30', ramp:45 })`
  → 0..1，开灯/关灯各有 45 分钟渐变（日出/日落）。夜里鱼按现有 `sleep` 入睡——真实的夜晚里，缸也睡了。
  手动按 Dock 日/夜按钮 = 关掉跟随（与现在"手动切换即关闭自动循环"一致）。开关落盘。
- **改动**：`scene/daynight.js`（或新纯模块 `systems/light-timer.js`）、`ui/settings-panel.js`、`index.html`、`main.js`、
  `tests/light-timer.test.js`（新）。
- **验收**：单测覆盖开灯前、渐变中、白天、关灯渐变、深夜、跨午夜；浏览器里桩掉 `Date` 验证 21:50 是月光、鱼在睡。
- 风险：低。默认**关**（决策 #2）。

#### B5 开缸清澈化 ⭐⭐ ✅
- **做法**：新增 `systems/turbidity.js`：`kick(strength)` + `update(dt)` → 浊度 0..1（约 5 秒指数回落，纯函数可测）。
  触发：新建空缸、某个水景**首次**进入（存一个已见过的场景 id 列表）、造景保存后（"刚动过底床，水有点浑"）。
  表现：玻璃缸把镜头 pass 的 `uDensity / uMaxMix` 临时调高，悬浮颗粒数 ×3 再回落；自然水域调高雾密度、降低 `uClear`。
  不做任何数值、不影响鱼。
- **改动**：`systems/turbidity.js`（新）、`main.js`（切场景 / 编辑器保存时 `kick`，每帧写 uniform）、`systems/effects.js`（悬浮颗粒可见数量）、
  `tests/turbidity.test.js`（新）。
- **验收**：新建水景时水由微浊转清；再次进入不触发；造景保存后轻微触发；`bloom(false)` 下检查无 NaN 黑块。
- 风险：低（注意浊度上限，别让最低画质档关掉镜头 pass 时出现跳变）。

## 四、阶段 C · 习性与互动

> 工程约束：`school.js` 已有 481 行（超出 400 行规范），新习性一律写进新模块 `entities/fish/habits.js`
> （纯函数、传入向量原地写、零分配，与 `steering.js` 同一风格），`School` 只加编排调用。
> 每个习性都加物种字段开关 + `__aqDebug` 钩子，GLB / 程序化两种模式都要跑通。

#### C1 物件锚点 `ctx.anchors`（基础设施）
- **做法**：`scene-runtime.apply()` 在重建 `obstacles` 的同一处，按物件类型汇总世界坐标锚点
  `anchors: Record<type, {x,y,z,r}[]>`（r = 占地半径 × 缩放），**原地维护**同一对象（与 `obstacles` 一致）；`main` 放进每帧 `ctx`。
- **改动**：`scenes/scene-runtime.js`、`main.js`。
- **验收**：调试钩子 `anchors()` 返回值随拖动物件实时更新。

#### C2 小丑鱼安家海葵 ⭐⭐⭐
- **做法**：物种字段 `host:'anemone'`。每两条小丑鱼按距离分到一株海葵（稳定分配，海葵增删时重分）；
  不觅食、不受惊时在海葵上方触手高度绕小圈、偶尔下潜"蹭"一下，游速降低；喂食时离家抢食，吃完回家；
  缸里没有海葵 → 退回普通群游。
- **改动**：`entities/fish/habits.js`（`hostAcc`）、`entities/fish/species.js`、`entities/fish/school.js`、`debug.js`（`hostOf`）、`tests/habits.test.js`（新）。
- **验收**：珊瑚礁预设里小丑鱼 60 秒内 ≥ 60% 的时间位于所属海葵半径内；喂食时照常来抢；删掉所有海葵后恢复群游。
- 风险：中（与 Boids 合力的平衡要在浏览器里调）。

#### C3 领地依托物件 ⭐
- **做法**：`territory` 增可选 `near:['wood','coralFan','coralBranch','rock']`：椭圆中心取离默认中心最近的那类锚点，
  半径按锚点半径放大；没有这些物件时退回现在的固定椭圆。顺带把领地力从 `school.js` 挪进 `habits.js`。
- **验收**：拖动沉木，蝴蝶鱼的盘旋中心跟着走；空缸行为不变。
- 风险：低。

#### C4 摄食习性：鹦鹉鱼啃藻、鼠鱼翻沙 ⭐⭐
- **做法**：
  - 物种字段 `grazes:[…]`（鹦鹉鱼：岩石/活石/太湖石/脑珊瑚/鹿角珊瑚）：不觅食时每 8–15 s 挑一个附近锚点，
    游到其表面（锚点中心 + 半径方向近似），播一次 `bite` 动作，复用 `Feeder` 碎屑崩出 2 粒，配一声很轻的"咔"。
  - 鼠鱼 `bottomRest` 趴沙时扬起一小团细沙（沙色碎屑，缓慢沉降）。
- **改动**：`entities/fish/habits.js`、`entities/fish/species.js`、`entities/fish/school.js`、`systems/feeder.js`（碎屑接口可指定颜色）。
- **验收**：珊瑚礁预设里 1 分钟内可见鹦鹉鱼啃岩 ≥ 3 次；鼠鱼趴沙时扬沙；喂食时两者都正常抢食。
- 风险：中（"抵达表面"是近似，需要目测不穿模）。

#### C5 讨食 ⭐⭐⭐
- **做法**：`ui/tank-input.js` 监听 `pointermove`（非拖拽、非编辑器、非拍照模式）：射线落到前玻璃平面（玻璃缸）或水面（自然水域），
  指针停留约 0.6 秒后 `ctx.beckon = { p, k }` 的 k 渐升，移开后渐降。
  鱼受吸引力 = k × 食欲 × 物种 `curious`（金鱼/锦鲤高、脂鲤中、鼠鱼/麒麟为负——害羞的反而稍稍躲开），只作用于感知半径内的鱼。
  吃饱的鱼不理人；这时点一下喂食，聚过来的鱼正好开抢。触屏没有悬停，先不支持。
- **改动**：`ui/tank-input.js`、`entities/fish/habits.js`（`beckonAcc`）、`entities/fish/species.js`、`entities/fish/school.js`、`main.js`、
  `debug.js`（`beckon(x,y)`）、`tests/habits.test.js`。
- **验收**：饥饿时指针停在前玻璃 3 秒，点周围 0.6 半径内的鱼数 ≥ 基线 2 倍；饱食度 > 0.9 时无明显变化；麒麟鱼不靠近。
- 风险：中（不能让鱼糊在玻璃上——吸引点放在玻璃后 0.15，并保留分离力）。

#### C6 小鱼对肉食鱼敬而远之 ⭐
- **做法**：A1 的 `predator` 物种与体长 ≤ 其 0.7 倍的异种之间，异种分离半径 ×2.2。小鱼在狮子鱼周围自然空出一圈，没有追逐。
- **改动**：`entities/fish/steering.js`（**线性与网格两条路径都要改**，现有单测校验两条路径等价）、`tests/steering.test.js`。
- **验收**：经典混养里脂鲤到狮子鱼的最近距离中位数明显增大；网格/线性等价单测仍通过。
- 风险：低。

#### C7 浮性饲料 + 水面抢食 ⭐⭐⭐
- **做法**：
  - `Feeder` 新增浮性饲料：浮在 `waterY` 随波起伏 8–12 秒后才缓慢下沉。投喂配比由水域/物种自动决定，玩家不选：
    自然水域或缸里有锦鲤/金鱼时，10 颗里一半是浮食。
  - 物种字段 `surface:true`（锦鲤、金鱼）：追浮食时水层上界临时抬到 `waterY - 0.04`、鱼头上仰，咬中时在水面打涟漪 + 一声"啵"
    （`sound.plop` 已有）。其他鱼够不着浮食，等它沉下来再吃。
- **改动**：`systems/feeder.js`、`entities/fish/steering.js`（觅食选靶看 `surface`）、`entities/fish/school.js`（上仰 / 水层上界）、
  `main.js`、`tests/feeder.test.js`、`tests/steering.test.js`。
- **验收**：睡莲池塘喂食时锦鲤浮上水面抢食、水面一圈圈涟漪；脂鲤不去抢浮食；浮食 12 秒后下沉，底栖鱼照常吃沉底片。
- 风险：中（俯视机位下鱼头出水的穿模；水面不写深度时的观感需实测）。

#### D1 在缸时长 ⭐⭐ ✅
- **做法**：`care` 存档新增 `since:{物种:[时间戳…]}`；新鱼入缸（里程碑 / 编辑器加鱼）记当前时间。

#### D2 漂袋过水入缸演出 ⭐⭐
- **做法**：`grantArrival` 时先在水面前部放一只半透明的鱼袋（车削几何，随 `WAVE_GLSL` 同款波面起伏），
  新鱼以 0.45 体型被钉在袋里约 3.5 秒（"过温"），然后袋口倾斜、鱼游出，袋子淡出，接上现有的从小长大。
  袋中阶段鱼不参与 Boids（状态位，类似 `bottomRest`）。
- **改动**：`systems/arrival-bag.js`（新）、`entities/fish/school.js`（`addFish(…, { hold:true })` + `release`）、`main.js`、
  `debug.js`（新增 `arrive(id)`：走 `grantArrival` 全流程；现有 `addFish` 钩子直连 runtime，不经过演出）。
- **验收**：`__aqDebug.arrive(id)` 触发完整演出，GLB 与程序化鱼都正确；演出期间切场景不残留袋子。
- 风险：中。

#### D3 水草缓慢生长（远期，按决策 #3）
- **思路**：编辑器里设定的尺寸就是"成熟尺寸"；新种下的水草按真实天数从成熟尺寸的 0.8 倍缓慢长到 1.0 倍（软进展），
  长满后不再变化；编辑器里始终显示成熟尺寸。存档按物件 id 存生长量，与 care 同一套离线结算。
