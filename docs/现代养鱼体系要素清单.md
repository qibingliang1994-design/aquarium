# 现代养鱼体系要素清单 × 本游戏对照表

> 目的：把"现代观赏水族养殖体系"的要素完整枚举一遍，并逐项对照本仓库（治愈系桌面水族箱）当前
> **已有 / 部分实现 / 未实现** 的状态，作为后续内容规划与设计讨论的底稿。
> 对照基准：v2.1.11 代码现状（2026-10-19 逐项对照源码复核），已同步任务分解第一批（v2.1.12）；改动见文末修订记录。
> 落地任务见 [养鱼要素任务分解.md](养鱼要素任务分解.md)。
> ⚠️ 所有建议必须遵守设计红线（DESIGN.md）：**不做任务列表、不做硬经济、不做内购**——
> 现代养鱼里的"监测数据、维护纪律"等要素只能以治愈化的方式呈现，不能变成压力系统。

---

## 一、要素总览

现代养鱼（观赏水族）体系通常分为八大子系统：

| # | 子系统 | 一句话概括 |
|---|--------|-----------|
| 1 | 水体化学 | 养鱼先养水：氨/亚硝酸盐/硝酸盐、pH、硬度、温度、水色 |
| 2 | 过滤系统 | 机械 + 生物 + 化学三级过滤，硝化菌床，出水造流 |
| 3 | 环境控制 | 加热/制冷、增氧、CO2、造浪、灯光光谱与光周期 |
| 4 | 造景（Aquascaping） | 底床、硬景（石/木）、水草/珊瑚、造景流派（含生态缸） |
| 5 | 生物规划 | 物种兼容性、密度、水层分工、习性、共生、清洁生物（虾/螺） |
| 6 | 投喂管理 | 饲料种类、投喂节奏、过量风险、人鱼互动（讨食） |
| 7 | 维护与监测 | 换水、测水、除藻、清洗滤材、记录 |
| 8 | 健康管理 | 检疫与过水、常见病识别与处置、应激管理、繁殖 |

## 二、逐项对照

图例：✅ 已有（玩家可感知）｜🟡 部分/表现层模拟｜❌ 未实现｜🚫 与设计红线冲突，建议不做
「（新增）」= 本次复核补充的要素。

### 1. 水体化学

| 要素 | 现代养鱼中的角色 | 本游戏状态 | 说明 |
|---|---|---|---|
| 氨 / 亚硝酸盐 / 硝酸盐循环 | 毒性核心指标，硝化系统成熟度的标志 | 🚫 | 作为数值机制不做；"开缸养水"只做视觉暗示（见下） |
| pH / 硬度（GH/KH） | 决定物种适配（三湖慈鲷 vs 南美灯鱼） | ❌ | `themes.js` 只有视觉水体风格；图鉴已标淡水/海水（A1），pH 与硬度本身不做机制 |
| 水温 | 热带/冷水鱼分界的硬约束 | 🟡 | 物种已有冷水/温水/热带标签（`entities/fish/ecology.js`）：图鉴胶囊 + 冷热水混养小知识（A1/A2）；有意不做温度机制 |
| 开缸养水（cycling） | 新缸前 2–6 周建立硝化菌 | 🟡 | 纯视觉（B5）：新建空缸、首次进入某水景、造景保存后，水由微浊约 5 秒转清（`systems/turbidity.js`）；无数值、无惩罚 |
| 换水（老水 vs 新水） | 常规维护核心动作 | ❌ | 见第 7 节 |
| （新增）水色：清水 / 单宁茶水 / 绿水 | 沉木单宁、黑水缸、池塘绿水 | 🟡 | `river` 主题"微茶色河水"即单宁水的视觉；自然水域 `env.clear` 控制通透度；无黑水、无绿水 |
| （新增）浑浊度 / 悬浮物 | 水体通透度的直观指标 | 🟡 | 悬浮颗粒（marine snow）+ 镜头 pass 水雾（`uDensity/uMaxMix`）表达浊度；开缸/造景后会变化（B5：玻璃缸 `uTurb` 加浓水雾、颗粒最多 ×3；自然水域雾加浓、`uClear` 降低） |

**小结**：游戏刻意把"水"处理成永远健康的环境（治愈纯度），水体化学整体属于被有意省略的子系统。
视觉侧的抓手（水雾、悬浮颗粒、`uClear`）已经**动起来**（B5）：新缸/造景后几秒的微浊→清澈。

### 2. 过滤系统

| 要素 | 现代养鱼中的角色 | 本游戏状态 | 说明 |
|---|---|---|---|
| 机械过滤（滤棉） | 拦截颗粒物、水清的关键 | ❌ | 无可见过滤设备 |
| 生物过滤（硝化菌床） | 水质稳定的根基 | ❌ | 同上 |
| 化学过滤（活性炭等） | 除色除味 | ❌ | — |
| 过滤桶 / 上滤 / 挂壁过滤 | 设备形态 | ❌ | 缸壳（`tank-shells.js`）有灯罩、柜体，但无过滤器、进出水管 |
| 出水口造流 | 过滤的副产品即水流 | 🟡 | 只有溪流/小河的 `env.current` 全域水流（鱼顶流、饲料顺流）；**玻璃缸里水流恒为 0** |
| （新增）设备运行声 | 过滤器水声、气泵嗡声是"有缸的家"的声音记忆 | ❌ | `sound.js` 全场景共用一条棕噪声"水底低鸣"，不分缸型/水域 |

**小结**：过滤设备是现代养鱼最具辨识度的视觉与听觉符号（管、进出水口、细流声），可作为**纯装饰物件 + 声景**进入游戏而不引入任何数值。

### 3. 环境控制

| 要素 | 现代养鱼中的角色 | 本游戏状态 | 说明 |
|---|---|---|---|
| 加热棒 | 热带鱼刚需 | ❌ | — |
| 温度计 / 控温 | 监测 | ❌ | 可做成纯装饰，读数按在缸物种的冷水/热带属性显示（无机制） |
| 增氧（气石/气泵） | 溶氧保障 | ✅ | 气石是可放置物件；无气石时气泡隐藏。**限制**：多个气石只有第一个冒泡（`scene-runtime` 的 `air`） |
| （新增）CO2 系统 | 水草缸标配（钢瓶、细化器、计泡器） | ❌ | 可复用气泡系统做"细密、半途溶解"的细化器气泡 |
| 造浪泵 | 海水缸 / 大水体 | 🟡 | 同上 `current`；仅溪流/小河有，礁缸没有 |
| 灯光光谱 | 水草/珊瑚生长 + 观赏 | 🟡 | 灯色/强度/高度随缸壳款式（`tank-styles.js` 的 `light`），礁缸蓝白光；无光谱自定义 |
| 光周期（定时器） | 开关灯时间控制 | ✅ | 设置「跟随本地时间」（B4，默认关）：8:00 开灯、21:30 关灯，各 45 分钟渐变；与 180 s 演示循环互斥，按 Dock 日/夜按钮即关掉两者 |
| （新增）月光灯 | 夜间观赏 | ✅ | 夜间统一月光表（冷蓝主灯 + 微弱环境光）；明式缸有宫灯 |
| UV 杀菌灯 | 控藻控菌 | ❌ | 不可见设备，价值低，不建议做 |
| （新增）环境声（水声 / 鸟鸣 / 虫鸣） | 池塘、溪流户外养殖的氛围 | ❌ | 自然水域与玻璃缸同一条声床；昼夜不影响声音 |

### 4. 造景（Aquascaping）——覆盖度最高

| 要素 | 现代养鱼中的角色 | 本游戏状态 | 说明 |
|---|---|---|---|
| 底床（沙/泥/化妆沙） | 种植与微生物基质 | ✅ | `TANK.sandHeight` 沙底 + 分层底砂截面（`substrate.js`）+ `setSandColors` 主题 |
| 硬景：岩石 | 骨架结构 | ✅ | 河石/青龙石（断裂面 + 层理）、活石、太湖石（隐式场 + MarchingCubes） |
| 硬景：沉木 | 释放单宁、骨架 | ✅ | 渐细树皮管 + 根须 + 细枝。（勘误：蝴蝶鱼领地是缸中央的**固定椭圆**，与沉木位置无关） |
| 水草（前景草/丛生/茎类） | 荷兰式核心 | ✅ | `leaf-shapes.js` 曲面叶组合：草坪丛、莲座、带状、茎状，随水流倒伏摇摆 |
| 珊瑚/海水礁体 | 海水缸核心 | ✅ | `corals.js`（鹿角/脑/海扇/海葵）+ 礁缸缸壳 |
| 挺水/浮水植物 | 池塘/沼泽风格 | ✅ | 睡莲（浮叶贴水面波浪）、香蒲 |
| 中国园林要素 | 造景流派之一 | ✅ | 太湖石、石拱桥、青花瓷罐、明式红木缸、水墨远山 |
| 风格流派 | 现代造景竞赛体系 | 🟡 | 8 个预设：经典混养 / 珊瑚礁 / 锦鲤石庭（≈岩景 Iwagumi）/ 荷兰草缸 / 睡莲池塘 / 山间溪流 / 林间小河 / 江南园林。缺**生态缸（Biotope，如亚马逊黑水）**与水陆缸 |
| （新增）落叶 / 榄仁叶 | 黑水生态缸的标志性底床 | ❌ | — |
| （新增）水草生长与修剪 | 草缸的时间维度 | ❌ | 物件尺寸只由编辑器决定，不随时间变化 |
| 缸体规格（超白/黑框/礁缸/木框） | 现代养鱼的"硬件审美" | ✅ | 5 种缸壳（经典/超白/礁缸/和风/明式）+ 3 种自然水域 |
| 卵石滩/岸边过渡 | 自然风格细节 | ✅ | 卵石滩物件；自然水域岸线软过渡、泡沫、浅滩 |

### 5. 生物规划

| 要素 | 现代养鱼中的角色 | 本游戏状态 | 说明 |
|---|---|---|---|
| 物种兼容性 | 混养成败第一要素 | 🟡 | 行为层"和平共处"（异种按体长之和分离）。预设里的淡海水 / 冷热水混养按决策 #1 保留，改为非阻断的**混养小知识**（A2：淡海水 > 冷热水 > 肉食鱼配小鱼，显示在造景鱼群页与图鉴页脚）；「荷兰草缸」里的 `angel` 仍是海水蝴蝶鱼，待 A3 拆分 |
| （新增）物种生态属性 | 淡水/海水、冷水/热带、性情 | ✅ | `entities/fish/ecology.js`：水 / 水温 / 是否吞小鱼；图鉴两个胶囊；单测保证 `FISH_IDS` 全覆盖（A1） |
| 密度管理 | 拥挤度 | 🟡 | 编辑器步进器有单种/总数上限（`FISH_MAX` / 90），为性能约束而非水质约束——保持即可 |
| 水层分工 | 上/中/底栖全覆盖 | ✅ | `band` 游泳水层、`hug` 贴沙底栖（鼠鱼、麒麟）、图鉴标注水层 |
| 习性表达 | 领地/群游/夜行 | ✅ | 群游 Boids、领地盘旋、贴底停顿、夜间睡眠；领地不绑定任何物件 |
| （新增）共生关系 | 小丑鱼 × 海葵是海水缸的招牌画面 | ❌ | 图鉴写着"喜欢在海葵触手间穿梭安家"，行为里没有；珊瑚礁预设里放了 5 株海葵 |
| （新增）摄食习性 | 刮藻、翻沙、啄珊瑚 | ❌ | 图鉴写着鹦鹉鱼"以藻类为食"、鼠鱼"常在沙地上觅食"，行为里只有吃投喂的饲料 |
| （新增）清洁生物（虾/螺/寄居蟹） | 现代草缸/海缸标配，"清洁队" | ❌ | 完全缺失；也是最治愈的"慢动物"（螺爬玻璃、虾啄苔） |
| 个体识别 | 现代养鱼的"识鱼"乐趣 | ✅ | 确定性命名 + 实时个性标签（P2.1） |
| 成长 | 鱼的体型变化 | ✅ | 个体累计吃 30 颗体长 +25%，持久化（P1.4）；新鱼入缸另有 0.45→1 的"从小长大"动画（P2.2） |
| （新增）在缸时长 | "这条鱼养了多久"是鱼友最常聊的数字 | ✅ | care 存档 `since`（D1）：识鱼卡显示"在缸第 N 天"/"今天刚到"；旧存档的鱼从升级当天算起 |

### 6. 投喂管理

| 要素 | 现代养鱼中的角色 | 本游戏状态 | 说明 |
|---|---|---|---|
| 投喂节奏 | 定时定量 | ✅ | 饱食度：吃到才计，约 3 分钟饿回来，离线按墙钟衰减（P1.1） |
| 过量投喂风险 | 现实中=残饵坏水 | 🟡 | 饱食度 ≥0.96 时食欲≈0，饲料沉底约 26 秒后淡出——无惩罚的软反馈，保持即可 |
| 饲料种类（薄片/颗粒/沉底锭/活饵） | 不同物种/水层投喂 | 🟡 | 每次固定 10 颗缓沉颗粒 + 缸里有底栖鱼时**自动附带**快沉的沉底片；玩家不能选，也没有浮性饲料 |
| （新增）水面抢食 | 锦鲤/金鱼池最具代表性的画面 | ❌ | 饲料一入水就下沉；锦鲤水层上界 1.53 离水面 1.84 还差 0.3，嘴碰不到水面 |
| 抢食行为 | 饥饿度可见化 | ✅ | 食欲→兴奋上限与感知半径、惊吓期间不觅食 |
| 进食反馈 | 满足感 | ✅ | 咬食动画 + 碎屑 + 音效 + 个体冷却（P1.3） |
| （新增）讨食 / 认主 | 鱼认得喂食的人，人一靠近就聚到前玻璃 | ❌ | DESIGN P5 诊断的"手（光标）靠近没反应"至今未处理；鱼对指针没有任何反应 |
| 禁食/清肠 | 健康管理 | 🚫 | 不做更符合治愈定位 |
| （新增）自动喂食器 | 出差/定时投喂 | 🚫 | 没有饥饿惩罚，它没有存在理由；而且会拿走玩家唯一的照顾动作 |

## 四、评估结论

1. **最大的缺口不是"缺设备"，而是"常识错位"**。8 个预设里有 2 个淡海水混养（经典混养、荷兰草缸），
   另有 2 个冷热水混养（山间溪流、林间小河），经典混养里还有狮子鱼配霓虹灯；编辑器也不作任何提示——懂鱼的玩家第一眼就会出戏（生态标签与混养小知识已在第一批补上）。成本最低的修正是给物种打生态标签 + 非阻断的"混养小知识"，
   而不是加限制；`angel` 物种位的语义漂移（开发记录叫"神仙鱼"、图鉴是海水蝴蝶鱼、却出现在淡水草缸里）已决定拆分成淡水神仙鱼与海水蝴蝶鱼（任务分解 A3）。
2. **文案写了、行为里没有**：小丑鱼安家海葵、鹦鹉鱼啃藻、鼠鱼翻沙、领地依托沉木——物件和鱼都已存在，
   补上它们是整份清单里性价比最高的一组。
3. **投喂只有一种吃法**：池塘/园林缺锦鲤水面抢食，人鱼之间缺"讨食"——现代养鱼里最强的牵挂瞬间
   （"它认得我"），恰好也是 DESIGN P5 留下的唯一未处理诊断。
4. **设备与氛围可以零数值补齐**：加热棒/温度计/过滤管/CO2 作为装饰物件，过滤水声/溪流/虫鸣作为声景，
   再加"灯跟随本地时间"（第一批已落地）——桌面水族箱从"开着玩"变成"放着陪"。
5. **对原"低成本补全建议"的调整**：
   - 原 #4「大型鱼追小鱼但永不追上」→ 改为「小鱼对肉食鱼敬而远之」：追逐画面本身就是压力，与治愈定位相悖。
   - 原 #2「按 diet 细分三种饲料」→ 收敛为「浮性饲料 + 水面抢食」：饲料由水域/物种自动决定，玩家不需要选（选择 = 认知负担）。
   - 原 #1、#3 保留并细化；原 #5「水草生长」保留为远期，需先定它与编辑器缩放的关系。
   - 新增：讨食、共生、摄食习性、漂袋过水、在缸时长、本地时间光周期、声景、清洁生物、生态缸预设。

## 五、明确不做清单（红线对照）

- 任务式日常（"今日换水"）、连续登录 —— 压力来源
- 水质数值面板、测水试纸道具、化学指标 —— 数据化压力
- 疾病 / 死亡 / 治疗玩法、检疫缸 —— 与治愈纯度根本冲突
- 换水、清洗滤材等"不做就变坏"的维护义务 —— 同上
- 自动喂食器、禁食日 —— 无饥饿惩罚，没有存在理由
- 捕食 / 攻击演出（包括"追而不得"）—— 画面即压力
- 货币、鱼买卖、内购 —— 既有红线
